# Privacy

Privacy Center exposes toggles: Microphone, System Audio, Screen Capture, Cloud Transcription, Cloud AI, Session Recording. Defaults: minimal retention, no raw-audio persistence unless explicitly enabled.

User controls: delete session / transcript / recordings / account data; export data. Transcript/audio/screen content is never logged by default. Capture modes: never / manual / on-question / periodic, with pause + privacy mask + per-window exclusion.
